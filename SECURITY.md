# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting on the
[Security tab](https://github.com/shapeshed/wenmoon/security/advisories/new), or
email george@shapeshed.com.

Please include:

- the affected version
- steps to reproduce
- any relevant logs or configuration (with API keys removed)

We aim to acknowledge reports within 7 days.

## Supported versions

The latest published release receives security fixes.
